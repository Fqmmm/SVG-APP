# ADR 006：内容检查点与标签 dirty 语义

状态：实现完成，通用准备、根配置接入与代码装配分别提交。

## 选择

modified-star 按“当前模型内容与最近成功读取或保存的模型内容不同”标星。编辑后 undo 回到保存点时星号消失；redo 再出现。执行了命令但内容未变，例如 move 0 0，不标星。

新建文档没有已持久化检查点，不读取快照即可标星；画布及新建节点立即标星，包括空画布。成功 read 后将解析结果视为已加载内容，所有行干净；自动补 ID 等导入警告不另行制造 dirty。成功 save 更新检查点；失败读取、解析、快照投影或写文件不更新它。init 创建新的文档身份，不复用同 ID 的旧基线。

对子图形的修改向祖先传播到画布。节点比较包含自身 ID、类型、父 ID、几何、样式、Provider 的持久化文本以及有序子树。删节点使其父节点和祖先标星；被删除节点本身没有可显示的行。更换父级会使移动节点与两侧祖先标星；仅在同父级调整顺序时，父节点及祖先标星，未改内容的叶子不标星。画布尺寸变化只影响画布和其整体状态，不让每个叶子标星。

多个标签按注册顺序以一个空格连接。默认先加载 box、再加载 modified-star，因此显示 `g#n (box) *`；反向注册为 `g#n * (box)`。两个插件互不导入，也不查询对方是否存在。

## 通用契约准备

原 TreeDecorator 上下文只包含 document 和 shape，缺少保存点通知和通用内容投影。为此先补以下接口，具体标签仍通过原扩展点注册：

- DocumentSnapshot 是不可变内容投影。属性键排序后比较，忽略写入属性的先后顺序；保留父级和子节点顺序。内容不依赖 show/tree 的展示文案。
- ShapeViews.snapshot 从注册的 ShapeProvider.text 读取正文，与 SVG 序列化使用相同的 elementText 策略。没有针对 text、box 或其他类型名的分支。
- TreeNodeContext 的可选 snapshot 为一次整树快照。RegisteredTreeFormatter 提供懒 getter，首次被标签读取时生成，同次查询所有行共享它；标签不读取时不生成。未传 document 的独立 subtree 展示仍不调用标签。
- TreeDecorator 的可选 checkpoint(document, snapshot) 接收成功读写检查点。回调只能更新实例内部状态，不修改文档、不执行 I/O。宿主逐个捕获回调异常，报告 error: checkpoint failed: <name> 后继续通知其他标签；诊断出口自身抛错也被隔离，不反转已完成的 I/O。故障标签自身的内部状态不作恢复承诺。已有只读标签无需实现它。
- 装配层 CheckpointRepository 包装原 DocumentRepository。write 在写文件前构造快照，原仓库成功返回后通知；read 完成解析与快照构造后通知。没有 checkpoint 监听者时直接委托原仓库，不构造快照。它不识别命令名或标签名，也不改变 EditorSession 的历史规则。createEditor 的报告出口默认使用 console.error，CLI 则传入自己的输出通道。

modified-star 把检查点保存在自身 WeakMap 字段中，以文档对象为键。每次 activate 创建新的标签实例；模块级单例只负责注册，不持有 dirty 数据。tree、show、stats、dir 不建立检查点，也不改变历史。原有 save/read/canvas 撤销屏障保持不变；本节点没有增加跨 I/O 撤销能力。

## 边界与验证

本轮工作区包含通用准备及标签接入，包含真实通用准备，不能把整体相对 HEAD 的差异当作“新增标签不改内核与渲染器”的 Git 证据。框架节点当时只提供 document/shape 上下文，遗漏了有状态标签需要的保存点通知；本次确实由标签需求推动了契约和渲染器改动。分步提交只能证明“准备后的接入不再改动内核与渲染器”，不能据此声称本次从原 HEAD 起严格满足 §5 的零改动判据。此项保留为验收限制。通用准备需要先单独提交，之后的插件接入不得再修改内核、渲染器、加载器及既有插件。对应文件分组见 [标签节点说明](../TREE_LABELS.md)。每一步提交都必须重新采集当时源码的 metrics，并运行完整测试。

独立状态机覆盖新建、保存、编辑、undo/redo、文本、删移顺序、尺寸变化、文档与实例隔离。集成测试覆盖先保存后首次 tree、失败读写、两种标签顺序、任意注册文本类型和只读命令。配置与代码装配使用同一会话、同一工作目录，逐字节比较 stdout 与重新保存的 SVG；禁用标签时保留 Phase 1 原有预期。

## 本轮审查修正

checkpoint 回调异常由宿主逐个隔离，保证成功 save/read 完成路径及屏障记账，并让健康标签收到同一检查点。真实 CLI 回归验证错误诊断、保存成功反馈、无参数再保存和读取后的屏障。

DocumentSnapshot.same 对任一侧缺失的 ID 返回 false。快照按需计算；当前每节点仍保存子树字符串，深链内容投影的时间与内存为 O(n²)，本轮没有更换为哈希协议。

[三阶段验证记录](../labels-stage-validation.json)由 npm run test:label-stages 生成，核验临时 detached 工作树的源码与测试组合，不是提交证据或逐阶段文档核验。准备阶段 328 项、独立配置阶段 344 项、最终阶段 345 项通过，指标分别在各阶段源码树上重新采集并校验。
