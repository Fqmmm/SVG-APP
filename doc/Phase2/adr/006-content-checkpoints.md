# ADR 006：通用内容检查点准备

状态：已实现，具体有状态标签另行接入。

DocumentSnapshot 保存不可变的规范化内容，包含 ID、类型、父级、几何、样式、Provider 正文和有序子树；属性插入顺序不影响结果，缺失 ID 不视为相等。当前子树字符串表示在深链上仍有 O(n²) 开销。

TreeNodeContext 提供按需生成、同次查询记忆化的快照。TreeDecorator 可以实现 checkpoint 接收成功读写基线。装配层 CheckpointRepository 在写文件前投影内容、写入成功后发布；读入完成并投影后发布。没有监听者时跳过投影。

checkpoint 回调必须只更新自身状态，不得修改文档或执行 I/O。宿主捕获回调异常并报告 error: checkpoint failed: <name>，随后继续通知其他监听者；诊断出口异常也被隔离，不能反转已完成的 I/O。CLI 诊断先输出，随后仍给出正常读写成功反馈。

此准备确实由后续有状态标签的需要推动，框架节点原先遗漏了保存点通知。它不能被包装成“首次新增标签时渲染器零改动”；后续接入可证明准备之后不再修改它。

DocumentSnapshot 与 CheckpointRepository 共 10 项测试覆盖内容、结构、懒投影、通知顺序、故障隔离及投影失败的路径/文档/redo 保持。准备阶段共 328 项 CLI 测试，指标对应 124 个源码文件。
