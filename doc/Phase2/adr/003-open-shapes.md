# ADR 003：开放图形协议与文本持久化

状态：采用。

具名 `visitRect`、`visitCircle` 等回调让消费者依赖完整图形集合。现在 `ShapeVisitor` 使用 `visitShape`，由基类统一分发；图形负责几何行为与状态恢复，Provider 负责 schema、帮助、展示和 SVG 表示。

文本持久化使用 `schema.hasText` 与 `text(shape)` 的对应协议，注册时检查一致性，写出时检查值为字符串。容器的 CLI 文本参数可通过 `svg.text: "children"` 显式保存为子图形，此时无需父元素正文访问器；默认元素正文策略用于容器时直接报错。展示回调只服务摘要、位置和属性显示，序列化器不调用它。这样自定义文本图形即使没有展示实现，也能通过默认读取路径保存和恢复正文。复合提供者的 `fromSvg` 应按自身 schema 保留输入语义。

解析器先检查父节点，再构造子树。普通图形先经过默认读取逻辑，叶节点在递归前拒绝子元素；自定义导入通过可选 `validateSvg` 预检属性、直接文本及元数据。普通分组在该预检中拒绝非法文本与 kind，保持 Phase 1 的错误优先级。随后递归解析子图形，再由 `fromSvg` 构造完整复合图形。

内核在自定义导入后核对普通属性与元素正文的值。属性未在公开几何/样式中保留，或正文与文本访问器结果不一致时拒绝输入；不匹配的 kind 必须拒绝或有降级警告。这样预检方法是否存在都不会成为跳过保真检查的依据。

提供者必须保留子图形的身份与顺序，返回的类型和 id 也必须匹配。通过校验后，文档统一登记整个子树，提供者无需操作私有结构句柄。

`svg.tag` 与 `svg.kind` 描述文件表示。映射歧义时拒绝解析；缺少精确 kind 提供者时尝试基础标签提供者，由它决定降级或拒绝。普通分组保留旧 box 降级行为，具体名称留在 `GroupProvider`。`canUngroup` 能力决定容器是否允许拆组。

取舍：旧具名 Visitor 的 TypeScript 调用需要迁移，CLI 命令和文件语义保持兼容。Provider 接收公共输入对象，不接收 XML DOM、文件系统或历史栈。

验证覆盖六类图形的具体几何值与文本、自定义文本 Unicode/转义往返、仅导入 SDK 的 tile、panel 元数据与完整子树，以及父子节点同时非法时的错误优先级。
