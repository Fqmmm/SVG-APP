# 框架扩展代码审查处理记录

后续目录整理已移除旧路径转发文件，默认构造入口现位于 `composition/defaults`。下表保留当时的处理记录；当前结构见 [源码目录说明](../../src/README.md)。

本轮按审查编号核对并修改，范围保持在“框架可扩展”节点。

| 意见 | 决定与修改 | 验证 |
|---|---|---|
| D1 文本读写判据不一致 | 采纳。新增 `ShapeRegistry`，注册时校验 `hasText` 与独立 `text(shape)`；保存不调用展示回调 | `ReviewRegression.test.ts` 覆盖缺失访问器、反向冲突、Unicode/转义往返、旧 content 字段及非法返回值 |
| D2 父子错误优先级 | 采纳。默认父节点读取与 `validateSvg` 在递归之前执行，完整对象仍在子图形解析后构造 | 两个复合非法输入逐字断言原有错误 |
| D3 插件可导入装配层 | 采纳。插件只能导入插件或公开 SDK | 虚拟源码反例覆盖 composition、main 和私有 domain 导入 |
| G1 缺少类实现 | 采纳。六个 Provider 类、`BoundCommand`、`HelpCommand` 及两个 examples 类显式实现扩展契约 | 默认行为与 opt-in 类插件测试 |
| G2 两个扩展点只有测试实现 | 采纳。交付 `ShapeTypeDecorator` 和 `StyleAttributeHandler` 类示例，默认关闭 | `ExamplePlugins.test.ts` 独立注册并验证调用及撤销；正式星号和 box 插件按后续节点实现 |
| G3 缺分类行数 | 采纳。`summary.linesByRole` 同时报告基线和当前数据 | 三角色虚拟源码精确统计；README 数据表 |
| G4 仅有角色图 | 采纳。生成具名模块图，公开 SDK 独立显示 | 图生成测试检查模块名和 SDK；采集结果可复现 |
| G5 清单缺错误处理 | 采纳。在四个扩展点清单中增加违规与失败处理列 | 对照实际异常位置和测试 |
| S1 门面豁免可能藏逻辑 | 采纳。旧路径只转导出；默认构造集中在 `composition/compat`，AST 拒绝转导出入口出现执行代码 | 虚拟门面加入表达式时检查失败 |
| S2 多余包装与重复工厂 | 部分采纳。删除 Attribute/PositionFormatter；文件仓库共享工厂。保留现有调用方仍使用的默认构造入口 | 原 formatter 输出断言迁移到 ShapeViews，文件与完整会话回归 |
| S3 内置图形有三份映射 | 采纳。每个 Provider 类集中声明定义、帮助、展示和文本访问，删除 presentation 映射 | 六类图形、默认 help 和 SVG 回归 |
| S4 未知图形暴露内部错误 | 采纳。展示和序列化统一经工厂查询，输出 `unknown shape type: ... (is the plugin loaded?)` | 序列化未知文档图形的错误测试 |
| S5 扩大属性处理器权限 | 本轮不采纳。属性事务只覆盖目标子树内可恢复的状态，当前实例与回滚测试已足够验证。box 必要子部件的结构保护应在 box 节点由文档/结构操作契约处理 | ADR 002 维持明确的副作用边界 |
| S6 测试强度与组织 | 采纳。恢复具体几何/文本断言，集中 import、修复缩进；空名称使用独立错误 | Visitor、完整会话和注册错误回归 |

审查列出的 metrics 静默过期风险也已处理：验证源码集合、各文件、生成器及产物摘要，测试同时覆盖有效快照和过期快照。

首轮修复结束时 CLI 256 项测试通过。后续三项修复见下节，范围仍限于框架与导入契约。

## 第二轮审查：三项补充修复

| 意见 | 处理 | 回归证据 |
|---|---|---|
| F1 叶节点结构错误优先级 | 内置叶节点在解析子元素类型之前拒绝子元素 | rect、circle、ellipse、line、text 五类错误逐字断言 |
| S-1 自定义导入可丢弃输入 | 内核校验普通属性、正文和 kind；预检回调不构成豁免 | 缺失/改写属性、丢弃正文、空预检、合法属性往返、失败读取保留原文档及 redo |
| S-2 容器正文被忽略 | 默认正文用于容器时拒绝；显式子图形策略保留 CLI 文本参数 | 创建与独立序列化拒绝、子图形正文往返、叶节点不得滥用子图形策略 |

新增 `ImportContracts.test.ts`，并加强原有非法文本访问器测试，让导入和独立序列化均须拒绝错误值。这轮框架修复结束时 CLI 265 项测试通过。

## 命令插件审查修复

| 问题 | 处理与证据 |
|---|---|
| CommonJS 包解析与 import 不一致 | 固定依赖 import-meta-resolve 4.2.0；import-only 和 import/require 双入口包均验证实际 import 分支 |
| cwd 查询异常越过错误边界 | cwd 查询和 entries 读取统一捕获；路径不可用时报告 `<cwd unavailable>` |
| 嵌套具名清单覆盖包根 | bare specifier 使用 findPackageJSON 定位包根；文件入口向上查找带 contributes 的清单；两条入口均测试具名 dist 清单 |
| 错误前缀可伪装框架异常 | 暂存注册、宿主冲突和清单校验使用专用错误类型；插件抛出的相同前缀保留插件名并报告激活失败 |
| 验证及测试缺口 | 补形状回滚、注册后契约改写、真实模块求值异常、cwd 异常、OTHER/未知 kind；双装配使用相对模块路径，并删除旧 SVG 后验证重新生成 |
| 装配及测试路径绑定 | 代码装配按项目 package.json 定位；会话 fixture 基于 import.meta.url，独立运行不依赖测试启动 cwd |

保留激活结束时的完整复核，测试证明它能拒绝初次注册后被改变的形状契约。插件本轮以仓库构建布局交付，独立 npm 制品的包内构建与 SDK 发布另行处理。当前 CLI 295 项测试通过。
